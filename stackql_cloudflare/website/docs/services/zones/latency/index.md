Retrieves aggregate Argo Smart Routing analytics for a zone, including latency improvements, bandwidth savings, and routing statistics.

```sql
SELECT
errors,
messages,
result,
success
FROM cloudflare.zones.latency
WHERE zone_id = '{{ zone_id }}' -- required
AND bins = '{{ bins }}'
;
```
