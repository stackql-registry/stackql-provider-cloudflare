<Tabs

Lists all of a user's subscriptions.

```sql

errors,
messages,
result,
result_info,
success
FROM cloudflare.user.subscriptions
;
```

## `REPLACE` examples

<Tabs
    defaultValue="update"
    values={[
        { label: 'update', value: 'update' }
    ]}
>
<TabItem value="update">

Updates a user's subscriptions.

```sql
REPLACE cloudflare.user.subscriptions
SET 
frequency = '{{ frequency }}',
rate_plan = '{{ rate_plan }}'
WHERE 
identifier = '{{ identifier }}' --required
RETURNING
errors,
messages,
result,
success;
```
</TabItem>
</Tabs>
