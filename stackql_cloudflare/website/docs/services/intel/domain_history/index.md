Gets historical security threat and content categories currently and previously assigned to a domain.

```sql
SELECT
categorizations,
domain
FROM cloudflare.intel.domain_history
WHERE account_id = '{{ account_id }}' -- required
AND domain = '{{ domain }}'
;
```
