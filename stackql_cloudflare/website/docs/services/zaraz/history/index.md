## `SELECT` examples

<Tabs
    defaultValue="list"
    values={[
        { label: 'list', value: 'list' }
    ]}
>
<TabItem value="list">

Lists a history of published Zaraz configuration records for a zone.

```sql
SELECT
id,
createdAt,
description,
updatedAt,
userId
FROM cloudflare.zaraz.history
WHERE zone_id = '{{ zone_id }}' -- required
AND offset = '{{ offset }}'
AND limit = '{{ limit }}'
AND sortField = '{{ sortField }}'
AND sortOrder = '{{ sortOrder }}'
;
```
</TabItem>
</Tabs>
