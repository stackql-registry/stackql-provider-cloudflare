Retrieves the email provider mapping configuration for DLP email scanning.

```sql
SELECT
addin_identifier_token,
auth_requirements
FROM cloudflare.zero_trust.account_mapping
WHERE account_id = '{{ account_id }}' -- required
;
```

account_id

'{{ account_id }}'
RETURNING
errors,
messages,
result,
success
;
