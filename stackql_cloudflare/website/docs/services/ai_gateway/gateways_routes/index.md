Get an AI Gateway Dynamic Route.

```sql
SELECT
id,
name,
gateway_id,
created_at,
deployment,
elements,
modified_at,
version
FROM cloudflare.ai_gateway.gateways_routes
WHERE account_id = '{{ account_id }}' -- required
AND gateway_id = '{{ gateway_id }}' -- required
AND id = '{{ id }}' -- required
;
```
