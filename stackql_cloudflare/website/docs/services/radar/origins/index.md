## `SELECT` examples

<Tabs
    defaultValue="get"
    values={[
        { label: 'get', value: 'get' },
        { label: 'list', value: 'list' }
    ]}
>
<TabItem value="get">

Retrieves the requested origin information with its regions.

```sql
SELECT
origin
FROM cloudflare.radar.origins
WHERE slug = '{{ slug }}' -- required
AND format = '{{ format }}'
;
```
</TabItem>
<TabItem value="list">

Retrieves a list of origins with their regions.

```sql
SELECT
regions,
slug
FROM cloudflare.radar.origins
WHERE limit = '{{ limit }}'
AND offset = '{{ offset }}'
AND format = '{{ format }}'
;
```
</TabItem>
</Tabs>
