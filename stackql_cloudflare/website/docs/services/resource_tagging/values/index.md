Lists all distinct values for a given tag key, optionally filtered by resource type.

```sql
SELECT
*
FROM cloudflare.resource_tagging.values
WHERE account_id = '{{ account_id }}' -- required
AND tag_key = '{{ tag_key }}' -- required
AND type = '{{ type }}'
AND cursor = '{{ cursor }}'
;
```
