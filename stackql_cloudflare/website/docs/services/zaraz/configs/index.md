Gets a history of published Zaraz configurations by ID(s) for a zone.

```sql
SELECT
errors,
messages,
result,
success
FROM cloudflare.zaraz.configs
WHERE zone_id = '{{ zone_id }}' -- required
AND ids = '{{ ids }}'
;
```
