<TabItem value="list">

List all Zero Trust certificates for an account.

```sql
SELECT
id,
binding_status,
certificate,
created_at,
expires_on,
fingerprint,
in_use,
issuer_org,
issuer_raw,
type,
updated_at,
uploaded_on
FROM cloudflare.zero_trust.accounts_gateway_certificates
WHERE account_id = '{{ account_id }}' -- required
;
```
