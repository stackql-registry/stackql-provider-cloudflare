Retrieves all ASes in the current global routing tables with routing statistics.

```sql
SELECT
asns,
meta
FROM cloudflare.radar.routes_ases
WHERE location = '{{ location }}'
AND limit = '{{ limit }}'
AND sortBy = '{{ sortBy }}'
AND sortOrder = '{{ sortOrder }}'
AND format = '{{ format }}'
;
```
