Lists publicly available fine-tuned models that can be used with Workers AI.

```sql
SELECT
id,
name,
created_at,
description,
model,
modified_at,
public
FROM cloudflare.ai.public
WHERE account_id = '{{ account_id }}' -- required
AND limit = '{{ limit }}'
AND offset = '{{ offset }}'
AND orderBy = '{{ orderBy }}'
;
```
