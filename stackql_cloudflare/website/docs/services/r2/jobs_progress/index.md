Retrieves current progress metrics for an R2 Super Slurper migration job

```sql
SELECT
id,
createdAt,
failedObjects,
objects,
skippedObjects,
status,
transferredObjects
FROM cloudflare.r2.jobs_progress
WHERE account_id = '{{ account_id }}' -- required
AND job_id = '{{ job_id }}' -- required
;
```
