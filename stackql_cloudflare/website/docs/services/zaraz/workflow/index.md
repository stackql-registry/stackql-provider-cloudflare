<Tabs
    defaultValue="list"

<TabItem value="list">

Gets Zaraz workflow for a zone.

```sql
SELECT
errors,
messages,
result,
success
FROM cloudflare.zaraz.workflow
WHERE zone_id = '{{ zone_id }}' -- required
;
```

messages,
result,
success;
