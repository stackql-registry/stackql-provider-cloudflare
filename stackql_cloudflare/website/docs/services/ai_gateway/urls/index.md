Retrieves the endpoint URL for an AI Gateway.

```sql
SELECT
result,
success
FROM cloudflare.ai_gateway.urls
WHERE gateway_id = '{{ gateway_id }}' -- required
AND account_id = '{{ account_id }}' -- required
AND provider = '{{ provider }}' -- required
;
```
