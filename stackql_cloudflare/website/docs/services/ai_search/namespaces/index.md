## `SELECT` examples

<Tabs
    defaultValue="get"
    values={[
        { label: 'get', value: 'get' },
        { label: 'list', value: 'list' }
    ]}
>
<TabItem value="get">

Read namespace.

```sql
SELECT
name,
created_at,
description
FROM cloudflare.ai_search.namespaces
WHERE account_id = '{{ account_id }}' -- required
AND name = '{{ name }}' -- required
;
```
</TabItem>
<TabItem value="list">

List namespaces.

```sql
SELECT
name,
created_at,
description
FROM cloudflare.ai_search.namespaces
WHERE account_id = '{{ account_id }}' -- required
AND page = '{{ page }}'
AND per_page = '{{ per_page }}'
AND search = '{{ search }}'
;
```
</TabItem>
</Tabs>

Update namespace.

```sql
REPLACE cloudflare.ai_search.namespaces
SET 
description = '{{ description }}'
WHERE 
account_id = '{{ account_id }}' --required
AND name = '{{ name }}' --required
RETURNING
result,
success;
```
