## `SELECT` examples

<Tabs
    defaultValue="list"
    values={[
        { label: 'list', value: 'list' }
    ]}
>
<TabItem value="list">

Get list of tails currently deployed on a Worker.

```sql
SELECT
id,
expires_at,
url
FROM cloudflare.workers.tail
WHERE account_id = '{{ account_id }}' -- required
AND script_name = '{{ script_name }}' -- required
;
```
</TabItem>
</Tabs>

script_name

'{{ script_name }}'

errors,
messages,
result,
success
;
