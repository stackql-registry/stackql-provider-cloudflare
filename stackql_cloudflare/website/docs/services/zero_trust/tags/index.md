## `SELECT` examples

<Tabs
    defaultValue="get"
    values={[
        { label: 'get', value: 'get' },
        { label: 'list', value: 'list' }
    ]}
>
<TabItem value="get">

Get a tag

```sql
SELECT
name,
app_count,
created_at,
updated_at
FROM cloudflare.zero_trust.tags
WHERE account_id = '{{ account_id }}' -- required
AND tag_name = '{{ tag_name }}' -- required
;
```
</TabItem>
<TabItem value="list">

List tags

```sql
SELECT
name,
app_count,
created_at,
updated_at
FROM cloudflare.zero_trust.tags
WHERE account_id = '{{ account_id }}' -- required
AND page = '{{ page }}'
AND per_page = '{{ per_page }}'
;
```
</TabItem>
</Tabs>

## `REPLACE` examples

<Tabs
    defaultValue="update"
    values={[
        { label: 'update', value: 'update' }
    ]}
>
<TabItem value="update">

Update a tag

```sql
REPLACE cloudflare.zero_trust.tags
SET 
name = '{{ name }}'
WHERE 
account_id = '{{ account_id }}' --required
AND tag_name = '{{ tag_name }}' --required
AND name = '{{ name }}' --required
RETURNING
errors,
messages,
result,
success;
```
</TabItem>
</Tabs>
