Retrieves the top domain categories by the number of robots.txt files parsed.

```sql
SELECT
meta,
top_0
FROM cloudflare.radar.robots_txt_top_domain_categories
WHERE limit = '{{ limit }}'
AND name = '{{ name }}'
AND userAgentCategory = '{{ userAgentCategory }}'
AND date = '{{ date }}'
AND format = '{{ format }}'
;
```
